# Jinx — готовые версии Prismaxys

Репозиторий используется только для публикации готовых клиентских версий:
сначала Windows, затем Android APK.

Сборка выполняется на серверах проекта. GitHub Actions для сборки, проверки
или развёртывания не используется. Серверная часть и бот хранятся отдельно.

Готовые файлы будут размещаться в Releases вместе с номером версии, описанием
изменений и контрольными суммами. Клиентские релизы пока не опубликованы.
