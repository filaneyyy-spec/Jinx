# Следующие шаги Prismaxys

Сейчас реализована основа бота: регистрация, проверка членства в канале и личное
меню. Платежи, VPN-подписки, выдача конфигураций, Mini App и клиенты ещё впереди.
Значения цены, срока, устройств и статуса остаются «—», пока правила не определены.

1. **Запустить и проверить бота в Telegram.** Добавить токен в секреты окружения,
   назначить бота администратором канала и указать настоящую ссылку вступления.
   Проверить `/start`, повторный вход, членство и помощь на реальных аккаунтах.
   Настроить постоянное хранение SQLite, резервное копирование и один процесс polling.
2. **Подготовить VPN-инфраструктуру.** Настроить маршрут через relay к серверу
   в Германии; проверить доступность, маршрутизацию и восстановление соединений.
   Секреты серверов хранить отдельно от репозитория.
3. **Сделать подписки и выдачу доступа.** Определить тарифы, сроки и лимиты устройств;
   реализовать состояния подписки, продление, истечение срока и отзыв доступа.
   Использовать один домен подписок для Happ/Hiddify и согласовать применение
   `bypasses.json`. Проверить совместимость на реальных клиентах перед выдачей пользователям.
4. **Разработать Mini App.** Подключить личный кабинет к состоянию подписки,
   проверять Telegram initData на сервере и публиковать приложение по HTTPS.
   Только после публикации добавить `JINX_MINI_APP_URL` в настройки бота.
5. **Подключить оплату.** Для цифровых услуг внутри Telegram использовать Telegram Stars.
   ЮKassa планируется на отдельном сайте: для интеграции понадобятся Shop ID и секретный
   ключ магазина, а не только provider token бота. Обрабатывать подтверждения платежей
   на сервере, проверять их подлинность и исключать повторную выдачу доступа.
   Перед продажами определить возвраты и поведение при сбоях оплаты.
6. **Сначала Windows, затем Android.** Подготовить установку, импорт подписки и понятный
   сценарий подключения для Windows; проверить весь путь от оплаты до доступа.
   После этого переходить к Android.

Ближайший шаг — предоставить токен через секреты окружения и права администратора
в канале, затем выполнить живую проверку бота. Основа проекта пока не означает
готовность платного сервиса к эксплуатации.
